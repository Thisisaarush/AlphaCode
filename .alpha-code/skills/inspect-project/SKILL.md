# Inspect Project

## Purpose
Quickly understand a new codebase by inspecting its structure, dependencies, and entry points.

## Steps
1. List the root directory to understand project structure
2. Check package.json (or Cargo.toml, go.mod, etc.) for dependencies and scripts
3. Identify entry points (main, index, app files)
4. Look for common patterns (MVC, modules, components)
5. Summarize the architecture and key files
