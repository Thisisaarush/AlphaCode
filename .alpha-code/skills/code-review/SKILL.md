# Code Review

## Purpose
Perform a thorough code review focusing on code quality, security, and best practices.

## Steps
1. Understand the scope - what files/changes to review
2. Check for common issues:
   - Security vulnerabilities (SQL injection, XSS, hardcoded secrets)
   - Error handling and edge cases
   - Code duplication
   - Performance concerns
   - Missing tests
3. Run linters/type checkers if available
4. Provide specific, actionable feedback
